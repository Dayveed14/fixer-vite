# Fixer frontend — changes (23 Oct 2026)

Deploy with the matching backend (change password, admin user editing and the
payments page need its new endpoints).

## Home banner
- The slideshow is replaced by "the workbench": a full-width blueprint stage with
  a big headline, tappable symptoms, and an illustrated laptop where FixBot runs
  a quick scan and lists the usual causes. "Get a full diagnosis" opens FixBot
  already filled in with the device and symptom.
- The "X Articles / X Repairs" placeholder stats are gone; the strip under the
  banner shows the three ways to get help with **live starting prices** from the
  pricing engine (support call, pickup zones).
- Respects reduced motion; works down to phone width.

## Dashboards — every card now goes somewhere
- **Admin:** stat cards (users, technicians, open tickets, revenue), ticket rows,
  system health items, technician list, revenue card. Dead quick actions
  ("View Reports", "Payment History", "Mail-In Repairs") now open Payments &
  Alerts, Mail-In Repairs and Pricing.
- **New Admin → Payments page:** every payment with filters (paid but not used,
  failed, mismatch…), each payment's history, and system health (unused
  payments, failures, server errors, recent alerts).
- **New Edit account page** for the admin Users/Technicians "Edit" buttons (they
  pointed to pages that didn't exist). Delete now shows the server's reason.
- **Customer:** stat cards, ticket rows (open the job; rating stars still work),
  activity items (open what they're about), upcoming appointment (opens it;
  readable date/time). "Live Chat" (did nothing) → "Book a Technician" and
  "Send Device for Repair". Empty states link to the next step.
- **Technician:** stat cards, job rows, today's schedule; Call / WhatsApp buttons
  for the current customer; the disabled "Upload Repair Report" placeholder is now
  "Report a Repair Result".
- Fixed: the technician dashboard's right-hand cards were squashed sideways by
  a CSS class shared with the admin dashboard.
- Fixed dead links: "My Profile" in all three menus, the admin sidebar "FAQ" item
  (no page). Payments added to the admin sidebar.

## Change password (all three dashboards)
- Settings now has a Change password card for customers, technicians and admins
  (one shared component). Same rules as the server; shows passwords on request;
  other devices are signed out, this one stays signed in.

## SEO
- **Fixed: the sitemap listed articles/videos by number** (`/userarticle/12`)
  while the pages and canonical tags use slugs, so those sitemap URLs didn't
  resolve and disagreed with their canonicals. Now slugs, published only.
- Draft previews and "not found" pages are `noindex`.
- Duplicate `robots.txt` / `sitemap.xml` in the project root removed (only
  `public/` is served).
- `scripts/seo.test.mjs` keeps sitemap, routes, canonicals and robots.txt consistent.

## Other
- CI: `.github/workflows/ci.yml` runs the tests and a production build.
- `README.md` rewritten; `.env.example` added.
- Tests: 176 (was 137).
